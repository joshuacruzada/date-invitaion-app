# Design Resources

These assets are standalone SVG resources for the Date Invitation project.

## Icons/assets

- `envelope.svg` — decorative envelope illustration
- `heart.svg` — heart
- `sparkle.svg` — decorative sparkle
- `ramen.svg` — ramen/date category illustration
- `arcade.svg` — arcade/date category illustration
- `cinema.svg` — cinema/date category illustration
- `painting.svg` — painting/date category illustration
- `calendar.svg` — calendar
- `mail.svg` — mail

## Icon rule

Use `lucide-react` for interactive UI icons inside React components. The SVGs are decorative resources and should not replace the Lucide component library.

Example:

```tsx
import { Heart, CalendarDays, Mail } from "lucide-react";
```
